# Rainbrand

Rainbrand is the brand layer for agents. It turns a brand's identity, guidance,
and assets into shared context that agents and products can use and update.

This directory contains Rainbrand's portable Agent Plugins 1.0 package. It
includes the Rainbrand Skill and the connection to
`https://mcp.rainbrand.com/mcp`. Complete OAuth sign-in in your client to connect
your account.

Use `portable/` as the plugin directory when installing or submitting from
this repository. For a registry with a source-path field, set that path to
`portable`. This package is separate from the Claude, Codex and Cursor
packages documented in the
[repository README](https://github.com/rainbrandai/rainbrand-skills#install).
